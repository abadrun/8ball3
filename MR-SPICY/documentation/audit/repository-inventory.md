## 4. Deliberate repository-design decisions

| Decision | Reason |
|---|---|
| The original IPA stays at the repository root, untouched, and is **referenced** (not copied) by `MR-SPICY/original/` | Copying a 98 MB binary would duplicate ~100 MB in Git for zero benefit and risks the two copies diverging. `original/reference/` records the exact path + checksum instead. |
| Extraction of the IPA was performed in `/tmp`, never inside the repository | Keeps generated/extracted third-party content out of version control. |
| All inspection output is JSON/CSV/Markdown generated by scripts in `validation/tools/` | Reproducible: re-running the tool on the same IPA reproduces the manifests byte-for-byte. |
| No upload timestamps, commit times or repository metadata were used anywhere in the design | Explicit requirement (§1). Dates appear only where a tool records its own run time. |
