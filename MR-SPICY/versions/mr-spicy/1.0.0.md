## Components in this version

Core: `SpicyTheme`, `SpicyL10n` + `SpicyStringKey`, `SpicyLayoutDirection`, `SpicyLayoutMetrics`,
`SpicyStateMachine`, `SpicyContentState`, `SpicyControlState`, `SpicyBrand`.

Components: `SpicyButton`, `SpicyCard`, `SpicySectionHeader`, `SpicyHeaderView`, `SpicyStatusBadge`,
`SpicyFeatureTile`, `SpicyFeatureTileGrid`, `SpicyModalView`, `SpicySettingRow`, `SpicySettingGroup`.

Containers: `SpicyOverlayViewController`, `SpicySettingsViewController`.

## Breaking changes

None — first release.

## Migration requirements

None.

## Known limitations

1. Never compiled or executed; no on-device verification of any runtime behaviour.
2. XCTest suites (28 cases) written but NOT ATTEMPTED.
3. No account / PRO / licence / entitlement / ad-countdown components — deliberate exclusion
   (see SCOPE-AND-BOUNDARIES.md §3).
4. `UIButton.contentEdgeInsets` deprecated on iOS 15+ (warning expected).
5. `ExistentialAny` upcoming-feature flag requires Swift 5.9+.
6. Three SF Symbol names used in the settings surface do not exist on iOS 13 and will render empty
   there unless replaced with custom images.
7. The light palette is implemented but unreviewed on hardware.
